# Tarot Cup, Website

Website von https://tarot-cup.com (GitHub Pages): Startseite, Datenschutzerklärung, Nutzungsbedingungen und Offenlegung.

Die gültigen Rechtstexte stehen auf Deutsch unter `/datenschutz/` und `/nutzungsbedingungen/`, auf Türkisch unter `/tr/gizlilik/` und `/tr/kullanim-kosullari/`. Jede Fassung steht mit Datum unter `/<text>/<fassung>/`, zum Beispiel `/datenschutz/1.0/` oder `/tr/gizlilik/1.1/`. Die Fassung 1.0 gibt es nur auf Deutsch, ab 1.1 gibt es beide Sprachen. Jede Rechtsseite verlinkt auf die andere Sprache.

Die Seiten werden erzeugt, nicht von Hand bearbeitet. Sie laden nichts von anderen Anbietern und setzen keine Cookies.
