Kebijakan Privasi untuk Tarot Cup

Versi 1.4 · Tanggal: 14 November 2026

Terjemahan ini hanya untuk informasi. Hanya versi bahasa Jerman yang mengikat secara hukum.

Kebijakan Privasi ini berlaku untuk aplikasi “Tarot Cup” dan situs webnya di https://tarot-cup.com. Untuk aplikasi, kebijakan ini berlaku bagi semua versi, termasuk versi uji. Di Google Play, aplikasi ini memiliki nama paket at.tonc.kaffeesatztarot.

1. Ringkasan hal terpenting

Aplikasi ini berfungsi tanpa akun, tanpa iklan, dan tanpa internet. Aplikasi ini tidak menjual data.

Semua pembacaan dibuat di ponselmu. Tidak ada kecerdasan buatan di dalam aplikasi dan tidak ada server yang menerima kartu, simbol, pembacaan, atau catatanmu.

Riwayat, catatan, dan setelan disimpan aplikasi di ponselmu. Salinannya hanya disimpan oleh cadangan ponselmu di Akun Google-mu, jika kamu mengaktifkannya.

Aplikasi hanya mengirim statistik penggunaan dan laporan error melalui Google Firebase jika kamu setuju. Pembacaan dan catatanmu tidak pernah ikut terkirim.

Aplikasi tidak menanyakan pertanyaanmu. Kamu cukup memikirkannya.

Situs web hanya memuat Google Analytics jika kamu setuju. Tanpa persetujuan, situs web hanya menyimpan pilihanmu dalam satu cookie yang diperlukan. Saat situs dibuka, penyedia hosting GitHub menyimpan alamat IP-mu untuk melindungi layanannya.

Data yang disimpan aplikasi dapat kamu hapus di dalam aplikasi atau dengan menghapus instalasi aplikasi. Jika ada pertanyaan, kirimkan email kepada saya. Pengaduan dapat kamu ajukan ke Otoritas Pelindungan Data Austria (Datenschutzbehörde).

Bagian A: Aplikasi

4. Apa yang disimpan aplikasi di ponselmu

Semua yang muncul selama penggunaan disimpan aplikasi di ponselmu. Saya tidak memiliki akses ke sana.

Riwayat. Untuk setiap pembacaan, aplikasi menyimpan: tanggal dan waktu, jenis pembacaan (misalnya kartu hari ini atau ampas kopi), kartu yang ditarik dan apakah kartu itu dalam posisi terbalik, untuk ampas kopi simbol yang dipilih beserta letaknya di cangkir dan bidang kehidupan yang dipilih, untuk tafsir mimpi berupa perasaan, bidang kehidupan, dan simbol yang dipilih, serta teks pembacaan.

Catatan. Untuk setiap pembacaan, kamu dapat menulis catatanmu sendiri, misalnya “Bagaimana akhirnya?”. Catatan tetap berada di ponselmu; jika pencadangan di Google aktif, salinannya dapat tersimpan di Akun Google-mu (bagian 7). Catatan tidak dimasukkan ke dalam gambar yang kamu bagikan (bagian 6).

Ritme bentangan. Setiap bentangan memiliki ritmenya sendiri, misalnya Tiga kartu setiap tiga hari. Karena itu aplikasi mengingat kapan terakhir kali kamu membuat setiap bentangan, serta kartu hari ini untuk hari tersebut, agar kartunya tetap sama sepanjang hari.

Setelan. Aplikasi mengingat: bahasa; apakah dan pada pukul berapa aplikasi perlu mengingatkanmu pada kartu hari ini; bahwa pada saat pertama kali dibuka kamu telah mengonfirmasi bahwa usiamu minimal enam belas tahun; versi Ketentuan Penggunaan mana yang telah kamu terima dan kapan; kapan versi baru pertama kali ditampilkan kepadamu, berapa bagian dari tenggat tiga puluh hari yang sudah berlalu, dan kapan terakhir kali aplikasi menghitungnya; berapa banyak pembacaan lengkap yang telah kamu selesaikan dan pada hari apa aplikasi terakhir kali memintamu memberi nilai (bagian 8); versi Kebijakan Privasi ini yang terakhir kamu buka di aplikasi (agar aplikasi dapat menandai versi baru satu kali, bagian 19); berapa kali kamu sudah mengocok kartu, agar petunjuk tentang mengocok hanya muncul pada beberapa kali pertama; dan apakah proses saat pertama kali dibuka sudah selesai.

Semua ini hanya diingat aplikasi di ponselmu. Apa saja yang boleh dicadangkan oleh sistem operasi dijelaskan di bagian 7, dan cara menghapusnya di bagian 14.

5. Pengingat kartu hari ini

Jika kamu mengaktifkan pengingat, aplikasi menjadwalkan notifikasi pada waktu yang kamu pilih. Untuk itu, sistem operasi meminta izinmu. Aplikasi baru meminta izin “Notifikasi” (POST_NOTIFICATIONS) saat kamu mengaktifkan pengingat, tidak sebelumnya. Ini adalah notifikasi lokal di ponselmu: pengingat dijadwalkan dan ditampilkan di ponselmu. Tidak ada yang dikirim, tidak ada server untuk itu, dan saya tidak meneruskan apa pun. Jika kamu menyetujui statistik penggunaan, yang dicatat hanya bahwa kamu mengaktifkan atau menonaktifkan pengingat (bagian 9). Waktu yang kamu pilih hanya disimpan aplikasi di ponselmu dan, jika ada, di cadangan (bagian 7). Agar pengingat tetap berjalan setelah ponsel dimulai ulang, aplikasi boleh menerima informasi tentang mulai ulang (izin RECEIVE_BOOT_COMPLETED). Aplikasi menggunakannya hanya untuk memasang kembali pengingat setelah mulai ulang, tidak untuk hal lain. Kamu dapat menonaktifkan pengingat di Setelan aplikasi atau di setelan ponselmu.

6. Membagikan sebagai gambar

Kamu dapat membagikan pembacaan sebagai gambar yang telah dirancang. Gambar itu menampilkan kartu atau simbol, satu kalimat dari pembacaan, tanggal, dan nama aplikasi. Catatanmu tidak tercantum di dalamnya. Aplikasi menyerahkan gambar ke menu Bagikan di ponselmu. Kamu sendiri yang menentukan ke aplikasi mana dan kepada siapa gambar itu dikirim. Aplikasi yang kamu pilih memproses gambar itu menurut ketentuannya sendiri. Tanpa langkah ini, tidak ada pembacaan yang keluar dari ponselmu, kecuali di dalam cadangan jika kamu mengaktifkannya (bagian 7). Jika kamu menyetujui statistik penggunaan, yang dicatat hanya bahwa kamu telah membagikan pembacaan atau aplikasi; gambar dan teks pembacaan tidak dikirim (bagian 9).

7. Pencadangan oleh sistem operasi

Ponselmu dapat mencadangkan data aplikasi jika kamu mengaktifkannya di setelan ponsel. Kamu sendiri yang menentukan di sana apakah pencadangan dilakukan. Pencadangan dilakukan oleh penyedia sistem operasimu dalam rangka akunmu di penyedia tersebut. Saya tidak memiliki akses ke sana.

Aplikasi mengizinkan pencadangan riwayat, catatan, bahasa, dan waktu pengingat, agar semuanya tetap ada saat kamu berganti ponsel. Yang tidak dicadangkan: ritme bentangan, konfirmasi usia, informasi tentang Ketentuan Penggunaan (versi yang diterima, waktu penerimaan, kapan versi baru pertama kali ditampilkan, dan status tenggat), informasi tentang permintaan penilaian, versi Kebijakan Privasi yang terakhir kamu buka, apakah pengingat aktif, dan apakah proses saat pertama kali dibuka sudah selesai. Informasi ini hanya berlaku untuk ponsel yang bersangkutan.

Di Android

Android menyimpan cadangan di Akun Google-mu, di area pribadi Google Drive, kira-kira sekali sehari dan biasanya hanya melalui Wi-Fi, serta memindahkan data juga saat kamu pindah ke ponsel baru. Dalam proses ini, data dapat sampai ke AS (bagian 13). Informasi lebih lanjut ada di kebijakan privasi Google: https://policies.google.com/privacy

8. Mendapatkan aplikasi melalui Google Play

Kamu mendapatkan aplikasi melalui Google Play. Google memproses segala hal yang berkaitan dengan pengunduhan, pembaruan, penilaian, dan program pengujian atas tanggung jawabnya sendiri dan menurut aturannya sendiri. Dari semua itu, saya hanya melihat apa yang ditampilkan Google kepada saya sebagai pengembang.

Instalasi dan akun. Pengunduhan dan pembaruan berjalan melalui Akun Google-mu. Saya tidak mengetahui siapa yang telah menginstal aplikasi.

Pemberitahuan versi baru. Saat dibuka, aplikasi menanyakan kepada Play Store di ponselmu apakah ada versi baru (pustaka “In-App Updates” dari Google Play). Menurut keterangan Google, untuk itu Play Store memproses informasi tentang perangkat, versi aplikasi, dan daftar modul serta paket aset yang terinstal, untuk mengetahui apakah ada pembaruan dan seberapa besar ukurannya. Menurut Google, data ini dienkripsi, tidak diteruskan kepada pihak ketiga, dan dihapus setelah jangka waktu tertentu. Jika ada versi baru, aplikasi menampilkan pemberitahuan di bagian atas layar Beranda; pembaruan diunduh dan diinstal oleh Google Play. Aplikasi tidak menyimpan apa pun untuk keperluan ini, dan saya tidak menerima data darimu. Jika kamu menyetujui statistik penggunaan, yang dicatat hanya bahwa pembaruan telah dicari (bagian 9).

Statistik. Jika di setelan ponselmu kamu telah setuju untuk membagikan data penggunaan dan diagnostik kepada Google, Android mencatat data error dan kinerja (di Google disebut “Android vitals”). Dari data ini, di Play Console saya hanya melihat statistik gabungan dan laporan error teknis, misalnya dengan model perangkat dan versi Android, tetapi tanpa nama dan tanpa data kontak. Selain itu, Google menunjukkan kepada saya angka gabungan tentang instalasi, penghapusan instalasi, dan penggunaan, menurut negara, bahasa, dan perangkat, tanpa data orang per orang.

Penilaian. Penilaian dan ulasan di Google Play bersifat publik dan memuat nama Akun Google-mu. Jika saya membalas sebuah ulasan, balasan saya juga bersifat publik. Mohon jangan menulis hal pribadi tentang dirimu atau orang lain di sana.

Penilaian di dalam aplikasi. Setelah pembacaan lengkap ketigamu (Tiga kartu, Cinta, atau ampas kopi “Baca sendiri” dengan minimal tiga simbol), aplikasi dapat meminta jendela penilaian dari Google Play begitu kamu kembali ke layar Beranda (pustaka “In-App Review”), dan setelah itu paling sering setiap sembilan puluh hari. Google yang menentukan apakah jendela itu muncul. Apa yang kamu masukkan di sana, yaitu bintang dan teks, dikirim secara terenkripsi ke Google dan muncul sebagai penilaian publik di Play Store; dalam pengujian tertutup, hanya saya yang menerimanya, tidak secara publik. Penilaianmu dapat kamu hapus di Akun Google-mu. Aplikasi tidak mengetahui apakah dan bagaimana kamu memberi nilai. Untuk keperluan ini, aplikasi hanya mengingat dua informasi di ponsel (bagian 4). Jika kamu menyetujui statistik penggunaan, yang dicatat hanya bahwa jendela penilaian telah diminta (bagian 9). Di Setelan, “Beri nilai aplikasi” membuka halaman aplikasi di Play Store.

Pengujian. Jika saya menguji versi baru dalam pengujian di Google Play, saya memasukkan alamat email Akun Google-mu ke daftar penguji agar kamu dapat ikut serta. Saya menggunakannya hanya untuk itu dan menghapusnya setelah pengujian selesai, atau lebih awal jika kamu menginginkannya. Versi uji tidak mengumpulkan data tambahan. Masukan dari para penguji saya catat tanpa nama.

Informasi lebih lanjut ada di kebijakan privasi Google: https://policies.google.com/privacy

9. Statistik penggunaan dan laporan error

Agar saya dapat melihat fungsi mana yang digunakan dan di mana aplikasi mengalami error, aplikasi menggunakan Google Analytics for Firebase dan Firebase Crashlytics, dua layanan Google Firebase, tetapi hanya dengan persetujuanmu. Penyedianya untuk pengguna di Eropa adalah Google Ireland Limited, Gordon House, Barrow Street, Dublin 4, Irland; selain itu juga Google LLC, AS. Dalam proses ini, data dapat sampai ke AS (bagian 13).

Hanya dengan persetujuanmu. Saat pertama kali dibuka, aplikasi bertanya satu kali kepadamu: “Maukah kamu membantu membuat Tarot Cup menjadi lebih baik?” Kamu memilih “Setujui” atau “Tolak”. Jika kamu sudah menggunakan aplikasi sebelumnya, aplikasi bertanya satu kali setelah pembaruan. Tanpa persetujuanmu, statistik penggunaan dan laporan error nonaktif, dan tidak ada yang dikirim.

Penarikan persetujuan. Kamu dapat menarik persetujuanmu kapan saja: di Setelan aplikasi, pada “Privasi”, dengan tombol “Statistik penggunaan dan laporan error”. Jika kamu menonaktifkannya, aplikasi menghapus pengenal untuk statistik di ponselmu.

Apa yang dikirim. Dengan persetujuanmu, Google menerima:

  • layar dan fungsi apa yang kamu gunakan, misalnya: kartu hari ini ditarik, bentangan dimulai atau diselesaikan beserta jenis bentangannya, baca sendiri ampas kopi dimulai atau diselesaikan beserta perkiraan jumlah simbol yang dipilih dalam kelompok, tafsir mimpi dimulai atau diselesaikan beserta perasaan dan bidang kehidupan yang dipilih serta perkiraan jumlah simbol yang dipilih dalam kelompok (tanpa simbolnya sendiri), kotak di layar Beranda diketuk beserta kotak yang mana, teks tentang fase bulan hari ini di “Bulan hari ini” dibuka beserta fasenya, pembacaan atau aplikasi dibagikan, pengingat diaktifkan atau dinonaktifkan, bahasa diganti, jendela penilaian diminta, pembaruan dicari,
  • bahasa aplikasi,
  • ID instans aplikasi acak dan ID instalasi Firebase,
  • model perangkat, versi Android, dan versi aplikasi,
  • perkiraan lokasi (kota, wilayah, negara) yang diturunkan dari alamat IP; alamat IP itu sendiri tidak disimpan oleh Google Analytics.

Saat terjadi error. Jika aplikasi mengalami error, laporan error teknis dikirim ke Firebase Crashlytics: titik di dalam program tempat kesalahan terjadi dan kondisi perangkat, misalnya ruang penyimpanan yang tersedia dan orientasi layar.

Apa yang tidak pernah dikirim. Pertanyaanmu (tidak ada kolom isian), teks pembacaan, catatanmu, riwayatmu, foto, ID iklan, dan lokasi persismu (misalnya melalui GPS). Tidak ada iklan, tidak ada Google Signals, tidak ada penautan dengan Google Ads, dan tidak ada ID pengguna.

Jangka waktu penyimpanan. Google Analytics menyimpan data selama empat belas bulan, Firebase Crashlytics menyimpan laporan error selama sembilan puluh hari.

Dasar hukum. Persetujuanmu, Pasal 6 ayat (1) huruf a GDPR dan § 165 Abs. 3 TKG 2021 (bagian 12).

Bagian B: Situs web

11. Situs web

Situs web dapat diakses di https://tarot-cup.com. Situs ini terdiri atas halaman yang sudah jadi, tanpa akun, tanpa formulir, dan tanpa program yang berjalan di server untukmu.

Pemberitahuan persetujuan. Saat pertama kali dikunjungi, situs web menampilkan pemberitahuan tentang persetujuan. Untuk itu, situs menggunakan alat sumber terbuka “CookieConsent”. Alat ini berjalan di situs web itu sendiri dan tidak memuat apa pun dari server pihak lain. Kamu memiliki tombol yang setara, “Terima semua” dan “Tolak”, serta “Setelan”. Di “Setelan”, kamu melihat dua kategori, yaitu “Diperlukan” dan “Statistik”. Menolak dapat dilakukan tanpa kerugian apa pun. Situs web menyimpan pilihanmu dalam cookie “cc_cookie” selama enam bulan. Cookie ini diperlukan agar situs web mengingat pilihanmu; untuk itu tidak diperlukan persetujuan (§ 165 Abs. 3 TKG 2021).

Statistik hanya dengan persetujuanmu. Hanya jika kamu setuju, situs web memuat Google Tag Manager dan Google Analytics 4. Penyedianya untuk pengguna di Eropa adalah Google Ireland Limited, Gordon House, Barrow Street, Dublin 4, Irland; selain itu juga Google LLC, AS. Google Analytics kemudian memasang cookie “_ga” dan “ga” dengan masa berlaku hingga empat belas bulan. Yang dicatat adalah halaman yang dibuka, waktunya, halaman asal kunjunganmu, jenis perangkat, browser, ukuran layar, bahasa, perkiraan lokasi (kota, wilayah, negara), dan apakah kamu mengeklik tautan ke Google Play. Alamat IP tidak disimpan oleh Google Analytics. Tidak ada iklan, tidak ada Google Signals, dan tidak ada penautan dengan Google Ads. Google Analytics menyimpan data selama empat belas bulan. Dalam proses ini, data dapat sampai ke AS (bagian 13). Dasar hukumnya adalah persetujuanmu (bagian 12). Informasi lebih lanjut ada di kebijakan privasi Google: https://policies.google.com/privacy

Mengubah dan menarik persetujuan. Pilihanmu dapat kamu ubah atau tarik kapan saja melalui tautan “Setelan cookie” di bagian bawah setiap halaman.

Penyimpanan di browser. Selain itu, di penyimpanan browsermu (localStorage) situs web hanya menyimpan apakah kamu telah menutup petunjuk bahasa. Informasi ini tidak dikirim.

Hosting. Halaman-halaman situs disimpan di GitHub Pages, layanan dari GitHub (untuk pengguna di Kawasan Ekonomi Eropa: GitHub B.V., Amsterdam, Belanda; perusahaan induk GitHub, Inc., AS). Saat sebuah halaman dibuka, GitHub menyimpan alamat IP perangkatmu untuk melindungi layanannya dari penyalahgunaan dan serangan; selain itu juga informasi teknis dari browsermu, seperti yang diterima setiap server web. Hal ini berlangsung atas tanggung jawab GitHub sendiri; saya tidak memiliki akses ke log tersebut. Dalam proses ini, data dapat sampai ke AS (bagian 13). Informasi lebih lanjut ada di kebijakan privasi GitHub: https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement

Alamat situs. Alamat tarot-cup.com dan kaffeesatz-tarot.com terdaftar di Hetzner Online GmbH (Gunzenhausen, Jerman). Server nama milik Hetzner menjawab pertanyaan di nomor mana situs web dapat diakses. Dalam proses ini, server tersebut melihat permintaan atas alamat itu, biasanya dari penyedia internetmu, tetapi tidak melihat halaman mana yang kamu buka. kaffeesatz-tarot.com dialihkan secara permanen ke tarot-cup.com melalui sebuah halaman yang juga disimpan di GitHub Pages.
